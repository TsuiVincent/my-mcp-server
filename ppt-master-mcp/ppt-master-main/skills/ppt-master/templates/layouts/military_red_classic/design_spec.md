# military_red_classic - 军队红经典

## I. 模板概述

| 属性 | 值 |
|------|-----|
| **模板名称** | military_red_classic（军队红经典） |
| **适用场景** | 陆军/合成旅/集团军汇报、八一建军节庆典、战备动员、国防动员讲话、军事仪式 |
| **设计基调** | 雄壮威武、热血忠诚、八一军徽+经典中国红 |
| **主题模式** | 深红渐变背景（封面/章节/结束页）+ 白色内容页 |
| **信息密度** | 中等，适合条令式汇报和仪式性展示 |

| 属性 | 值 |
|------|-----|
| **格式** | 16:9 |
| **尺寸** | 1280 × 720 px |
| **viewBox** | `0 0 1280 720` |
| **页边距** | 左右 50-120px，上下 30-100px |

## III. 核心设计原则

1. **主色**: 军红 `#C41E3A`，渐变至 `#6B0000`
2. **辅助色**: 金色 `#F5D68A`、`#C4A44A`（五角星、横条、分隔线）
3. **标志性元素**: 八一军徽五角星（封面居中/结束页居中）、金色双线横栏
4. **背景**: 封面/章节/结束页深红渐变，内容页纯白 `#FFFFFF`，目录页暖灰 `#FAFAFA`
5. **字体**: 标题 `SimHei`（黑体），正文 `Microsoft YaHei`，英文 `Arial`
6. **装饰**: 金色顶底线（封面/章节/结束页 6-8px）、红色左边条、金色编号文字
7. **风格**: 硬朗方正、棱角分明、军旅庄重感

## IV. 页面结构

- **封面**: 深红渐变 + 金色8px顶底线 + 八一五角星（居中上方）+ 标题/单位/日期
- **目录**: 暖灰背景 + 红色顶栏(含八一星) + 红色左条卡片式目录项 + 右侧红色调面板
- **章节页**: 深红渐变 + 金色6px顶底线 + 超大半透明章号 + 双金线框题
- **内容页**: 白色背景 + 红色渐变顶栏(含编号+标题) + 红色虚线内容区
- **结束页**: 深红渐变 + 金色6px顶底线 + 八一五角星 + 感谢语

## V. 禁止事项

- 不使用蓝色或绿色（保持军红忠诚色调）
- 不使用卡通或手绘元素
- 不使用过于圆润的边角
- 八一星不得变形或移位
- 金色不得使用亮金色（保持军旅稳重感，使用暗金 #C4A44A）

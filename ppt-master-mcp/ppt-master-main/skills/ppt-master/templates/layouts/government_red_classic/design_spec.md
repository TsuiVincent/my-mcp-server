# government_red_classic - 党政红经典

## I. 模板概述

| 属性 | 值 |
|------|-----|
| **模板名称** | government_red_classic（党政红经典） |
| **适用场景** | 党建工作汇报、政府工作报告、政治学习材料、红色文化宣传、爱国主义教育 |
| **设计基调** | 庄重、严肃、权威、经典中国红 |
| **主题模式** | 深红渐变背景（封面/章节/结束页）+ 白色内容页 |
| **信息密度** | 中等，适合条理清晰的结构化汇报 |

## II. 画布规范

| 属性 | 值 |
|------|-----|
| **格式** | 16:9 |
| **尺寸** | 1280 × 720 px |
| **viewBox** | `0 0 1280 720` |
| **页边距** | 左右 60px，上下 30-100px |

## III. 核心设计原则

1. **主色**: 中国红 `#C41E3A`，渐深至 `#5A0000`
2. **辅助色**: 金色 `#F5D68A`、`#D4A853`（用于边框、分隔线、装饰元素）
3. **背景色**: 封面/章节页深红渐变，内容页纯白 `#FFFFFF`，目录页暖灰 `#FAFAFA`
4. **字体**: 标题使用 `SimHei`（黑体），正文使用 `Microsoft YaHei`，英文使用 `Arial`
5. **标题字号**: 封面 54px，章节页 50px，内容页 26px
6. **装饰元素**: 金色五角星、金色横条分隔线、金色双线边框

## IV. 页面结构

- **封面**: 深红渐变背景 + 金色双边框 + 金五星装饰 + 标题/副标题/单位/日期
- **目录**: 暖灰背景 + 红色编号方块 + 右侧统计装饰面板
- **章节页**: 深红渐变 + 超大透明章号 + 金色横条 + 章节标题
- **内容页**: 白色背景 + 红色顶部条 + 页码章号块 + 虚线内容区
- **结束页**: 深红渐变 + 金色边框 + 金五星 + 感谢语 + 单位信息

## V. 禁止事项

- 不使用蓝色或冷色调（保持党政红暖色基调）
- 不使用卡通或手绘风格元素
- 不使用过于鲜艳的荧光色
- 内容页底色必须纯白，不可使用深色背景
